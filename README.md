# Sistema Académico ITI - Módulo CRUD con React.js y Axios

Aplicación web desarrollada con React.js, Vite y Bootstrap 5 para la gestión académica de estudiantes y asignaturas, conectada a una API REST en la nube mediante Axios.

## Requisitos previos

- Node.js (v18 o superior)
- npm
